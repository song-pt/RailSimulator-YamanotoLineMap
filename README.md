# RailSimulator — 山手线 iOS 全线地图

地图文件通过本仓库 **Releases** 下载，不放入 Git 历史。

- 地图：`CityLoop_FullV1_iOS.railmap`
- 大小：929,402,710 字节（约 886 MiB）
- 内容：全线、双方向、每方向 30 站。
- 平台：iOS，地图由 Unity 6000.6.4f1 构建；不是桌面版地图。
- 配套游戏源码：https://github.com/song-pt/RailSimulator

下载后在手机版游戏中选择“导入地图”，通过系统文件窗口选择 `.railmap` 文件。请勿将文件改名为 ZIP 后直接导入。

SHA-256：`4fb2f94034784d9c30bf808c4233914b88185e6eeb046532f70858d1039695e8`

地图沿用现存 iOS 全线 V1，本次仅分发，未重新修改建模内容。游戏及地图的真机体验仍需实际验证。

## 数据与素材来源

City footprints/rail geometry: OpenStreetMap contributors, ODbL, https://www.openstreetmap.org/copyright . Supplementary footprints/terrain: 国土地理院, https://maps.gsi.go.jp/ . Height offsets are inferred where no surveyed data exists. PBR textures: Poly Haven CC0. Models: independently generated modular FullV2, corrected city levels and station structures.
